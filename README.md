# 🌮 El Express de Sabores – API REST

## 🚀 Instrucciones para ejecutar

1. Clona o descarga este repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta el servidor:
   ```bash
   npm run start
   ```
   o en modo desarrollo (recarga automática):
   ```bash
   npm run dev
   ```
4. Abre tu navegador en:
   ```
   http://localhost:3000/
   ```

## 📚 Rutas disponibles

| Ruta | Descripción |
|------|--------------|
| `/` | Mensaje de bienvenida |
| `/menu` | Menú completo (tacos y bebidas) |
| `/menu/tacos` | Lista de tacos |
| `/menu/tacos/:id` | Detalle de un taco por ID |
| `/contacto` | Información del negocio |
